# Пик в 19:00

Интерактивный кейс операционной аналитики Екатерины Дружинской для команды «Самоката». Данные и экономические допущения синтетические.

[Открыть GitHub Pages](https://druzhinskaia.github.io/samokat-ops-case/)

Сценарии используют модель из `model.js`. Сырые данные пика доступны в `peak-raw.csv`. В книге `shift-analysis.xlsx` можно проследить валидацию и расчёт KPI. Для Power Query замените путь к CSV в первой строке `validation.pq` и выберите результат Valid или Rejected.
